怎么联机

  1. 房主在电脑上打开游戏，服务器会自动启动。
  2. 同一 Wi-Fi 的朋友：填大厅顶部的局域网地址。
  3. 外网朋友：填房主分享的 https://… 公网链接，或直接用浏览器打开该链接。

怎么操作

  1. 鼠标 / 手指控制方向，按住左键 / 空格加速。
  2. 撞上别人的身体会死；头对头时更大的蛇吞噬对方。
  3. 第一次死亡 3 秒后复活，之后淘汰。

生存法则

  • 吞噬头对头碰撞时，体型更大的蛇直接吃掉对方；体型接近则同归于尽。
  • 猎杀头撞到别人的身体，你会死，对方获得击杀与质量。
  • 复活每人 1 次复活：第一次死亡 3 秒后自动复活，第二次死亡淘汰观战。
  • 成长吃能量豆变长；死亡会沿身体爆出大量能量豆，谁抢到归谁。
