蛇域争霸 · Windows 桌面版
================================

【启动】
双击 SnakeArena.exe。
- 程序会自动在后台启动本地游戏服务器。
- 使用 Windows 自带的 WebView2 打开一个独立的游戏窗口，不需要安装 Node.js。
- 如果系统缺少 Microsoft Edge WebView2 Runtime，程序会提示；
  Windows 10/11 通常已随 Edge 自带。也可从微软官网安装 Evergreen Runtime。
- 本程序未做商业代码签名，Windows SmartScreen 可能提示
  “Windows 已保护你的电脑”；选择「更多信息」→「仍要运行」即可。

【联机（最多 5 人）】
1. 进入游戏后，大厅顶部会显示服务器地址，例如 192.168.1.10:31888。
2. 同一 Wi-Fi 下的朋友：
   - 手机安装 SnakeArena.apk，打开后在「服务器地址」里填入上面的地址；
   - 或者用手机 / 电脑浏览器直接打开 http://192.168.1.10:31888
3. 房主点「开始游戏」。
4. 首次启动如果 Windows 防火墙询问，请选择「允许访问」；
   若朋友连不上，请在防火墙中允许 node.exe 的专用/公用网络访问。
5. 如果 31888 被占用，程序会自动使用 31889 等端口；
   请以大厅顶部显示的地址为准。

【外网联机（不在同一 Wi-Fi）】
1. 在大厅左侧「外网联机」区域点「生成公网地址」。
2. 等待 5–15 秒，出现 https://xxxx.lhr.life 后点「复制链接」。
3. 外网朋友用浏览器直接打开该链接，或在手机 App 的服务器地址里粘贴；
   不需要路由器端口映射，也不要求同一 Wi-Fi。
4. 房主电脑需要能出站 SSH（默认 22 端口）并安装 Windows OpenSSH 客户端；
   Windows 10/11 通常已自带（设置 → 系统 → 可选功能 → OpenSSH 客户端）。
5. 免费隧道由 localhost.run 提供。链接是临时且公开的，任何拿到链接的人
   都能加入（最多 5 人）；不用时请点「关闭隧道」。延迟取决于线路，
   免费服务也可能限速或断开。

【操作】
鼠标 / 手指控制方向；按住鼠标左键或空格加速。
手机端：按住屏幕拖动转向（只点一下不会转向），右下角「加速」按钮。

【单人无尽】
连接页点「单人无尽 · 无需服务器」即可本地开局，不依赖局域网或公网。
吃豆变长，撞墙或咬到自己结束；没有倒计时，最高分保存在本机。

【玩法】
- 吃能量豆变长；撞到别人身体会死，头对头时体型更大的蛇吞噬对方。
- 每人 1 次复活：第一次死亡 3 秒后自动复活，第二次死亡淘汰观战。
- 对局开始后加入也会立即在安全位置生成，带 2.6 秒出生护盾，不用等下一轮。
- 道具：护盾、疾风、磁铁、双倍、复活币。
- 每局 4 分钟，按得分、击杀和长度排名。

【关闭】
关闭游戏窗口即停止本次启动的本地服务器。
WebView2Profile / launcher.log 是运行缓存与日志，可以随时删除。
